Description

This IT Support course prepares you for real-world IT support roles, covering everything from setting up and upgrading Windows to using everyday support tools.

You will practice hands-on system setup, troubleshooting, and basic networking, building the practical skills IT Support Specialists and Helpdesk Engineers use daily.

By the end of the course, you’ll be ready for entry-level roles such as IT Technician, Helpdesk Support Engineer, Desktop Support Officer, or Network Administrator.

Curriculum

  • Preparing installation media
  • Installing and activating Windows
  • Drivers and first-time configuration
  • In-place upgrades and backups
  • Updates and rollback
  • Remote support tools
  • Troubleshooting workflow
  • IP addressing and DNS
  • Wi-Fi, routers and connectivity checks
